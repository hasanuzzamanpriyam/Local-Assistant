# Task 1.1: Initialize Tauri + Svelte 5 Project

## Task Description

Initialize a Tauri 2 + Svelte 5 project with all necessary configuration files, dependencies, and a minimal working app structure.

## Files to Create

### Root Package Files
- `package.json` - with exact dependencies from plan
- `pnpm-lock.yaml` - will be generated by pnpm install
- `tsconfig.json` - with exact compiler options from plan
- `vite.config.ts` - with exact config from plan
- `svelte.config.js` - with static adapter from plan

### Tauri Configuration
- `src-tauri/Cargo.toml` - with exact dependencies from plan
- `src-tauri/tauri.conf.json` - with exact config from plan (transparent window, WebView2 bootstrapper)
- `src-tauri/build.rs` - minimal tauri_build

### Frontend Entry Points
- `src/main.ts` - imports styles, mounts App
- `src/App.svelte` - transparent window with titlebar (drag region, minimize/maximize/close buttons)
- `src/vite-env.d.ts` - Vite type declarations

### Styles
- `src/styles/variables.css` - CSS custom properties from plan
- `src/styles/global.css` - global styles, tailwind imports, scrollbar styling

### Tauri Main Entry (ADDED per pre-flight)
- `src-tauri/src/main.rs` - minimal Tauri entry point that loads config and sets up builder

## Acceptance Criteria

1. `pnpm install` completes without errors
2. `pnpm tauri dev` opens a window with:
   - Titlebar showing "Assistant"
   - Drag region on titlebar
   - Minimize, maximize, close buttons (functional via Tauri APIs)
   - Transparent background
   - No console errors
3. `cargo test` in src-tauri passes (config tests from Task 1.2 will be added later)

## Global Constraints (from plan)

- Target: HP EliteBook 845 G8, 16GB RAM, integrated Radeon, Windows 11
- Tauri 2, Svelte 5, TypeScript, Rust 2021
- Transparent, borderless window with custom titlebar
- WebView2 embedded bootstrapper
- Config at `$APPDATA/assistant/config.toml`
- RAM budget: <7GB idle, <9GB active
